# Kallback releases

Downloads of **Kallback**, a calm, local-first personal Kanban for your desktop.

- Get the latest `.dmg` from the [Releases](../../releases/latest) page, open it and drag Kallback to Applications.
- Kallback updates itself from here: the app checks this repository for new versions and verifies their signature before installing.
- For now: macOS on Apple Silicon (macOS 13 or later).

This repository only holds release files.
